プロ646人の統計では、**eDPIが160未満の人はわずか6%**でした。筆者のeDPI 122は、プロの中でもかなり低い部類に入ります。

それでもイモータル1まで上がれているので、「感度が低い＝不利」とは限らない、ということがわかります。

## 低感度（eDPI 160未満）のメリット・デメリット

| | 内容 |
|---|---|
| メリット | 手のブレがエイムに出にくく、頭の位置でピタッと止めやすい。遠距離の細かい調整がしやすい |
| デメリット | 振り向きに腕を大きく動かす必要がある。大きなマウスパッドが必要 |

VALORANTは、撃つときに立ち止まる必要があり、「一瞬で振り向いて撃つ」よりも「角で待って、出てきた頭を正確に撃つ」場面が多いゲームです。低感度のメリットが活きやすいゲームだと言えます。

## 低感度にするなら、マウスパッドのサイズに注意

ここが一番見落とされがちなポイントです。

筆者の設定（eDPI 122）では、**360度振り向くのに約107cm**、180度でも**約54cm**マウスを動かす必要があります。

一般的な「大きめ」のマウスパッドは横45cm前後なので、**180度振り向くだけでもはみ出してしまいます**。低感度にするなら、横80〜90cmクラスの特大マウスパッドを選ぶか、途中でマウスを持ち上げて戻す前提で使うことになります。

## 自分の感度を計算してみよう

DPIとゲーム内感度を入れると、eDPIと振り向きに必要な距離、プロの中での位置がわかります。

<div id="kando-calc" style="max-width:520px;border:1px solid #ddd;border-radius:8px;padding:1em 1.2em;">
  <label>DPI：<input id="kc-dpi" type="number" value="800" min="1" style="width:6em;"></label><br>
  <label>ゲーム内感度：<input id="kc-sens" type="number" value="0.152" step="0.001" min="0.001" style="width:6em;"></label><br>
  <button id="kc-btn" type="button" style="margin-top:0.8em;padding:0.5em 1.2em;background:#2a7ae2;color:#fff;border:none;border-radius:6px;cursor:pointer;">計算する</button>
  <div id="kc-result" style="margin-top:0.8em;"></div>
</div>

<script>
(function () {
  var bands = [
    [160, "プロの下位6%（かなり低感度）"],
    [200, "プロの下から約30%以内（低感度寄り）"],
    [240, "プロの中央値あたり（標準的）"],
    [280, "プロの中央値あたり（標準的）"],
    [320, "プロの上から約30%以内（やや高感度）"],
    [400, "プロの上位約20%（高感度）"],
    [Infinity, "プロの上位5%（かなり高感度）"]
  ];
  document.getElementById("kc-btn").addEventListener("click", function () {
    var dpi = parseFloat(document.getElementById("kc-dpi").value);
    var sens = parseFloat(document.getElementById("kc-sens").value);
    var out = document.getElementById("kc-result");
    if (!(dpi > 0) || !(sens > 0)) { out.textContent = "DPIと感度を入力してください。"; return; }
    var edpi = dpi * sens;
    var cm360 = 360 / (sens * 0.07) / dpi * 2.54;
    var pos = "";
    for (var i = 0; i < bands.length; i++) { if (edpi < bands[i][0]) { pos = bands[i][1]; break; } }
    out.innerHTML = "<p><strong>eDPI：" + edpi.toFixed(1) + "</strong>（" + pos + "）</p>" +
      "<p>振り向き（360度）：約" + cm360.toFixed(1) + "cm ／ 180度：約" + (cm360 / 2).toFixed(1) + "cm</p>" +
      (cm360 / 2 > 45 ? "<p>180度振り向くのに45cm以上必要です。大きめのマウスパッドがおすすめです。</p>" : "");
  });
})();
</script>

※振り向きの距離は、VALORANTの感度1あたりの回転量（0.07度）をもとに計算した目安です。

## 感度を決めるときのコツ

1. **DPIは800に固定**して、ゲーム内感度だけで調整する
2. まずは**プロの中央値（eDPI 230前後）**から始める
3. 「振り向きが間に合わない」なら上げる、「頭の位置で止まらない」なら下げる
4. **一度決めたら、しばらく変えない**。毎日のように感度を変えると、手が覚えられません

筆者のように低い感度でも高ランクには上がれます。大事なのは、プロの数字に合わせることではなく、**自分が安定して当てられる感度を見つけて、使い続けること**です。
